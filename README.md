# Android ADB Debloat List

## Disclaimer
**Use this at your own risk.** The author is not responsible for any damage, data loss, or bricked devices that may result from using these scripts. Always back up your data before proceeding.

## Directory Structure
The project is organized as follows:
`Brand / Model / Model Variant / Android Version`

## Supported Devices and Scripts
Each directory contains a `debloater.bat` and `restore.bat` (or equivalent `adb_commands`) targeting the specified Android version.
